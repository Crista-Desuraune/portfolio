## Présentation du projet

<Section sideImg="/images/soundspire-logo.png" sideAlt="logo du projet" sideSize="w-72 max-lg:w-full h-auto self-center">
Dans un projet de groupe, il nous a été demandé de créer un site de type blog sur n'importe quel sujet qui nous plaisait.
Nous avions plusieurs contraintes : les pages qu'il devait contenir ainsi qu'une certaine période pour travailler sur le projet.
Ce projet nous a permis d'acquérir de nouvelles notions du langage HTML, CSS et JavaScript. Pour travailler tous ensemble, nous avons utilisé GitHub, ce fut une découverte pour tous les membres et nous avons réussi à mener à bien le projet.
</Section>
